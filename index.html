ℹ️ Como funciona o acesso offline:

Para utilizar o aplicativo nos ensaios sem gastar a sua internet:

  • Primeira vez: Abra as músicas enquanto estiver conectado ao Wi-Fi para salvar os áudios no celular.
  • Uso offline: Depois de carregar, o aplicativo funciona sem internet.
  • Atenção: Se limpar o cache ou os dados do navegador do celular, você perderá os trechos salvos para repetir e precisará se conectar à internet mais uma vez para recarregar os áudios.
  • Nota: Os vídeos do YouTube precisam de conexão com a internet para rodar.
